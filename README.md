# 🗡️ Text-Based Adventure Game

A console-based adventure game developed using **Java**. Players can explore different locations, fight enemies, collect gold, manage inventory, use potions, level up, and complete quests.

## ✨ Features
- 🗺️ Explore villages, forests, caves, rivers, and castles
- ⚔️ Battle enemies and challenge the dragon
- 🎒 Inventory and weapon management
- 🧪 Use potions to restore health
- ⭐ Level-up and progress through the game
- 💰 Collect gold and earn rewards
- 💾 Save and load game progress

## 🛠️ Technologies Used
- Java
- Object-oriented programming concepts
- Java console input/output

## ▶️ How to Run
1. Install the Java JDK.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the program:
   `javac Main.java`
5. Run the game:
   `java Main`

## 🎯 Objective
Explore the world, defeat enemies, collect rewards, and complete your adventure by facing the dragon.

**Created as a Java programming project to practise programming logic, methods, loops, conditionals, and file handling.**
